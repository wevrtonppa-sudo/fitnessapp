🌾 AgroMax Fitness | Treino & Nutrição Inteligente

Um aplicativo web moderno, completo e inteligente desenvolvido para atletas de alta performance. Gerencie seus treinos, acompanhe sua ingestão de macronutrientes, hidratação, suplementos e utilize Inteligência Artificial (Gemini API) para analisar seu físico, identificar pontos fortes e fracos e gerar o treino perfeito.

🚀 Principais Funcionalidades

Dashboard de Alta Performance: Acompanhe em tempo real seu consumo de água, calorias ingeridas, metas de proteínas e treinos cadastrados.

Gerenciador de Treinos Completo: Crie e organize rotinas de treino por divisões (Push, Pull, Legs, Upper, Lower, Full Body), registrando exercícios, séries, repetições e cargas. Inclui também modelos de rotinas prontas para importação instantânea.

Dieta & Hidratação: Monitore refeições diárias com cálculo automatizado de macronutrientes (Calorias, Proteínas, Carboidratos e Gorduras) e contador rápido de água.

Controle de Suplementos: Checklist diário para creatina, whey protein, multivitamínicos e ômega-3.

AI Coach & Chat Virtual: Converse com um treinador e nutricionista virtual integrado (via Google Gemini API ou fallback inteligente) especializado em biotipos exigentes.

Análise de Físico por IA: Envie uma foto do seu físico, selecione seus pontos fortes e fracos atuais e receba um laudo detalhado com um treino hiper-customizado gerado automaticamente.

Persistência Local (LocalStorage): Todos os seus dados ficam salvos de forma segura diretamente no seu navegador.

🛠️ Tecnologias Utilizadas

HTML5 & CSS3 (Estrutura e estilização moderna)

Tailwind CSS (Framework CSS via CDN com tema personalizado agro)

FontAwesome & Google Fonts (Ícones e tipografia Inter)

JavaScript (ES6+) (Lógica, manipulação de DOM e integração com API)

Google Gemini API (Inteligência artificial para análises físicas e chats)

📦 Como Publicar no GitHub Pages (Passo a Passo)

Este projeto foi construído em um único arquivo (index.html), o que torna a hospedagem no GitHub Pages extremamente simples:

Baixe ou salve o código fornecido como um arquivo chamado index.html.

Acesse o GitHub e crie um novo repositório (ex: agromax-fitness).

Faça o upload do arquivo index.html para a raiz do seu repositório.

Vá em Settings (Configurações) do seu repositório no GitHub.

No menu lateral esquerdo, clique em Pages.

Na seção Build and deployment, em Branch, selecione main (ou master) e / (root), depois clique em Save.

Aguarde alguns segundos e o GitHub fornecerá o link público do seu site (ex: https://seu-usuario.github.io/agromax-fitness/).
